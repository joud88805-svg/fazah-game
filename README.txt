لعبة «فزعة 🇸🇦» — هوية خضراء سعودية — خطوات التشغيل والنشر

الملفات:
- index.html: اللعبة كاملة بملف واحد.
- هذا الملف: خطوات تفعيل لوحة الترتيب ونشر اللعبة.

1) تجربة اللعبة محليًا
افتحي index.html في متصفح. اللعبة تعمل، لكن لوحة الترتيب المشتركة لن تعمل حتى تكملي إعداد Supabase.

2) إعداد قاعدة البيانات المجانية
- افتحي https://supabase.com وسجّلي الدخول وأنشئي مشروعًا جديدًا.
- من لوحة المشروع افتحي SQL Editor ثم New query.
- الصقي SQL التالي واضغطي Run:

create table if not exists public.scores (
  id bigint generated by default as identity primary key,
  nickname text not null check (char_length(nickname) between 1 and 18),
  character text not null check (character in ('boy','girl')),
  score integer not null check (score >= 0 and score <= 100000),
  seconds integer not null check (seconds >= 0 and seconds <= 7200),
  created_at timestamptz not null default now()
);

alter table public.scores enable row level security;

create policy "Anyone can read scores"
on public.scores for select
to anon
using (true);

create policy "Anyone can submit scores"
on public.scores for insert
to anon
with check (
  char_length(nickname) between 1 and 18
  and character in ('boy','girl')
  and score between 0 and 100000
  and seconds between 0 and 7200
);

grant select, insert on public.scores to anon;
grant usage, select on sequence public.scores_id_seq to anon;

ملاحظة: هذا إعداد أولي عام ومفتوح؛ أي شخص يستطيع إرسال نتائج، وقد يحاول بعض المستخدمين تزوير النقاط. لا تخزني بيانات شخصية. لو أردتِ منافسة أكثر موثوقية، نحتاج تحققًا من النتائج عبر خادم/Edge Function وحدودًا لمعدل الطلبات.

3) ربط اللعبة بقاعدة البيانات
- في Supabase افتحي Project Settings ثم API (أو Data API بحسب واجهة المشروع).
- انسخي Project URL.
- انسخي مفتاح anon/public (لا تضعي أبدًا service_role أو secret key في المتصفح).
- افتحي index.html بمحرر نصوص.
- ابحثي عن:
  const SUPABASE_URL = "PASTE_YOUR_SUPABASE_PROJECT_URL";
  const SUPABASE_KEY = "PASTE_YOUR_SUPABASE_ANON_KEY";
- استبدلي القيمتين بالقيم التي نسختِها، مع إبقاء علامتي الاقتباس.
- احفظي الملف.

4) نشر اللعبة برابط مجاني عبر GitHub Pages
- افتحي https://github.com وأنشئي مستودعًا جديدًا باسم sahra-game.
- ارفعي index.html إلى المستودع في المستوى الرئيسي (Root).
- افتحي Settings ثم Pages.
- في Build and deployment اختاري Deploy from a branch، ثم branch main والمجلد /(root)، ثم Save.
- انتظري حتى يظهر رابط الموقع في صفحة Pages. افتحي الرابط وجرّبي اللعبة من الجوال.
قد تتغير أسماء القوائم قليلًا مع تحديث GitHub.

5) اختبار لوحة الترتيب
- افتحي الرابط من جهازين/متصفحين مختلفين.
- العبوا وأرسلوا النتائج.
- افتحي «ترتيب اليوم» و«الترتيب العام».
- «ترتيب اليوم» يستخدم بداية اليوم حسب ساعة جهاز اللاعب؛ في نسخة أكثر دقة يفضّل ضبط اليوم على توقيت السعودية من الخادم.

حدود النسخة الحالية
- لا تحتاج حسابات؛ الاسم المستعار فقط.
- الترتيب يعرض أفضل 10 محاولات، وليس أفضل نتيجة واحدة لكل اسم.
- بما أن اللعبة لا تطلب تسجيل دخول، يمكن تكرار الأسماء. لا تستخدميها لمنافسة بجوائز حقيقية قبل إضافة مكافحة الغش.
- هذه لعبة كرتونية خيالية لتفادي عوائق مرسومة؛ الصواريخ والمسيّرات عناصر لعب فقط.
